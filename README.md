Автономный запуск ИИ-агента [OpenCode](https://opencode.ai) внутри GitHub Actions для автоматизации разработки, рефакторинга и генерации Pull Request'ов.

## 📌 Как запускать вручную через интерфейс GitHub Actions

1. Перейдите во вкладку [Actions ➔ OpenCode AI Agent](https://github.com/gkosarintsev/opencode-in-actions/actions/workflows/opencode.yml).
2. Нажмите выпадающую кнопку **Run workflow** справа.
3. Заполните параметры:
   - **Запрос для OpenCode (Prompt)**: текст задания для агента.
   - **Путь к файлу с промптом (опционально)**: если вы хотите передать большое ТЗ или многострочный промпт, укажите путь к файлу (например, `PROMPT.md`). Если поле текста пустое, воркфлоу автоматически возьмет `PROMPT.md`!
   - **Модель LLM**: по умолчанию выбрана самая мощная бесплатная модель `opencode/deepseek-v4.1-flash-free`.
   - **Режим агента**:
     - `build` — полный доступ: создание, анализ и редактирование файлов репозитория.
     - `plan` — режим анализа и планирования без изменения кода.
   - **Создать Pull Request**: галочка (включена по умолчанию). При наличии изменений агент автоматически создаст новую ветку и откроет Pull Request.
4. Нажмите зеленую кнопку **Run workflow**.

## 📝 Как передать многострочный промпт (3 удобных способа)

В самом веб-интерфейсе GitHub Actions поле ввода технически является однострочным (ограничение платформы GitHub Actions `workflow_dispatch`), но вы можете передавать многострочные промпты тремя способами:

### Способ 1: Редактирование файла `PROMPT.md` в браузере (Рекомендуется для больших ТЗ)
1. Откройте файл [`PROMPT.md`](./PROMPT.md) в репозитории на GitHub.
2. Нажмите иконку **карандаша** (Edit) и напишите любой объем текста, требований и фрагментов кода в полноэкранном Markdown-редакторе.
3. Сохраните коммит и нажмите **Run workflow** (поле промпта можно оставить пустым — воркфлоу сам возьмет `PROMPT.md`!).

### Способ 2: Вставка многострочного текста или `\n` в поле
1. Скопируйте многострочный текст из редактора и вставьте (Ctrl+V) в поле ввода — GitHub корректно сохранит его.
2. Либо используйте `\n` для разделения строк:
   ```text
   Создай калькулятор на Python:\n- функции add, sub, mul, div\n- unit-тесты
   ```
   Воркфлоу автоматически преобразует `\n` в реальные переносы строк.

### Способ 3: Через терминал GitHub CLI (`gh`)
```bash
gh workflow run "OpenCode AI Agent" -f prompt="$(cat << 'EOF'
Реализуй фичу:
1. Валидация форм
2. Обработка ошибок
EOF
)"
```

## 📊 Где посмотреть результаты выполнения

1. **Job Step Summary (Сводка запуска)**:
   - Внизу вкладки **Summary** завершенного запуска отображается:
     - Использованный промпт.
     - Список измененных файлов (`git status`).
     - Интерактивный спойлер **Git Diff** со всеми правками.
     - Прямая ссылка на созданный **Pull Request**.
     - Полный лог консоли OpenCode.
2. **Pull Request**:
   - Агент автоматически открывает Pull Request с изменениями и описанием задачи.
3. **Artifacts (Артефакты)**:
   - Скачиваемый архив `opencode-artifacts-<run_id>` с файлами `changes.patch` и логами.
